年初给博客接了 Giscus，基于 GitHub Discussions，不需要自己维护后端。配置很简单，在仓库里开一个 Discussions 分类，把 ID 填进配置，页面底部就多了一个评论框。

一开始还挺新鲜。每发一篇文章，都会去看有没有人留言。大部分时候没有，偶尔有几条，是“写得不错”“学习了”之类的客气话。真正讨论内容的很少。

后来垃圾评论多了起来。有些账号会在每篇文章下面留一句无关的话，再附一个链接；有些干脆是英文的模板评论。Giscus 可以审核，但每次都要手动点，时间久了就懒得管。

真正让我决定关掉的，不是垃圾评论，而是那种“有人在看”的压力。写博客本来是自言自语，想到什么写什么；有了评论框之后，会不自觉地去想“这篇会不会有人问”“要不要解释得更清楚”。这种念头一多，写作就变慢了。

关掉评论的那天，我把 `commentConfig.ts` 里的 `type` 改成了 `"none"`，又顺手把留言板页面关了。世界没有因此安静多少，但写东西的时候轻松了一点。

现在想讨论文章内容，可以去 GitHub 仓库提 issue。那里不适合闲聊，但至少每条消息都有上下文。

写博客是自言自语。评论是另一种东西，我还没准备好。
